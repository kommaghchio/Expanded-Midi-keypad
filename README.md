# Expanded-Midi-keypad

The original Hack Club MIDI keypad (https://github.com/KaiPereira/MIDI-Keypad/tree/master), but with some additional features. 

Powered by a XIAO-ESP32-S3, this project creates a MIDI keypad that allows you to play individual notes on a variety of instruments, controlled by turning the rotary encoder. From there each of the 7 capacitive touch keys plays a different note. Finally, the OLED screen shows which instrument you have selected, along with a WinAMP style display.
